SynapseMail WHM plugin

Version {{VERSION}}. Sends the cPanel Webmail login (ports 2095/2096, webmail.<domain> and /webmail) to your SynapseMail address. cPanel and WHM logins stay as they are, and everything can be rolled back.

Install (as root on the WHM server)

bash <(curl -fsSL https://repo.synapsecyber.io/synapsemail/whm-plugin-only/install.sh)

The installer checks the SynapseCyber signature of the package before it changes anything.

Commands

smwhmpluginstatus
smwhmplugin -url URLchange the SynapseMail address
smwhmplugin -checkcheck Webmail, cPanel and WHM logins
smwhmplugin -rollbackturn the redirect off, restore the original login page
smwhmplugin -enableturn it on again
smwhmplugin -uninstallroll back and remove the plugin

The same controls are in WHM under Plugins › SynapseMail Webmail.
