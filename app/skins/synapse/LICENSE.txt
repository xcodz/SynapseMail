Scope
-----
This license covers the SynapseMail components:
  skins/synapse/                 SynapseMail interface (templates, styles, scripts), except skins/synapse/vendor/
  plugins/synapse_core/          security (passcode, 2FA, rate limits), sessions, installer, admin panel
  plugins/synapse_editor/        rich-text editor integration; in lexical.bundle.js only the SynapseMail code
                                 (the Lexical code in it is MIT licensed, see below)
  plugins/synapse_preview/       message preview text
  plugins/synapse_demo/          public demo (source repository and demo package only, not in the release)
  config/config.inc.php          SynapseMail configuration
  public_html/install.php, public_html/admin.php   installer and admin panel entry points
  In the source repository also: editor/ (the SynapseMail editor sources; the npm packages it builds with keep
  their own licenses), docker/, whm-plugin/, repo-site/, tools/, .github/
